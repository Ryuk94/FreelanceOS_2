# AGENTS.md

## Project Rules

- Preserve the current visual style, layout, spacing, typography, color palette, motion, and component structure unless the repository owner explicitly approves a visual redesign in the current request.
- Do not change the app's current look and feel "just because it seems better." Any layout or styling change requires express permission from the owner.
- Do not add demo, sample, placeholder, or seeded business data.
- Default gamification level must start at `0`.
- Keep changes focused and minimal. Avoid feature creep.
- If a requested change would alter the visual language, stop and ask for approval before editing.
